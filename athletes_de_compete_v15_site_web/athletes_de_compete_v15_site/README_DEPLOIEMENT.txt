ATHLÈTES DE COMPÈTE — VERSION SITE WEB

Le fichier principal est index.html.

MISE EN LIGNE LA PLUS SIMPLE
1. Ouvrir https://app.netlify.com/drop dans Chrome ou Edge.
2. Glisser-déposer TOUT le dossier athletes_de_compete_v15_site (ou le ZIP décompressé).
3. Netlify fournit une adresse HTTPS publique, par exemple https://nom-aleatoire.netlify.app
4. Envoyer cette adresse à l'autre joueur.
5. Les deux joueurs ouvrent la même adresse.
6. Sur l'écran d'accueil : Multijoueur en ligne.
7. Joueur 1 : Créer une partie et communiquer le code.
8. Joueur 2 : Rejoindre une partie et saisir le code.

POUR METTRE LE JEU À JOUR
Remplacer index.html par la nouvelle version et redéployer le dossier sur le même site Netlify.
Ainsi, les deux ordinateurs utilisent toujours la même adresse.

IMPORTANT
- Une connexion Internet est nécessaire pour Three.js et PeerJS.
- Utiliser l'adresse HTTPS donnée par l'hébergeur plutôt que d'ouvrir index.html en file:// pour le multijoueur.
- Le mode local reste jouable depuis le même site.
